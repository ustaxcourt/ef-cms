## Things we know
- Doing getCaseByDocketNumber or updateCaseAndAssociations in a Promise.all() or in parallel lambdas causes massive slowdowns. 700ms lambda can take 15s if other lambdas are executing at the same time.
- It takes ~800ms-900ms to getCaseBydocketNumber from zachs computer on average.
- doing selective database updates instead of updateCaseAndAssociations is signficantly faster. 1:30 vs 4s to qc 100 cases.
- Any queries that we do in parallel with multiple lambdas will cause the queries to get slower and slower. So selecting a single row from dwCase may take 20ms but if 100 lambdas are querying for data it could take 2s
- Parallel 50 lambdas doing caseByDocketNumber() timing varies 2s-7s and grows as more parallel
- Parallel 50 lambdas just fetching case row timing does not vary at 3s when more parallel calls
